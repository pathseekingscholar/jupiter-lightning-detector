About

What this workbench does

The detector scans Cassini Jupiter images and saves bright regions that may be worth human review. The system is deliberately conservative: a candidate is not confirmed lightning.

The public version contains a static detector-output snapshot. It is enough for review, explanation, and label collection. It cannot run new detector jobs by itself.

Detector Workflow

What happens inside the detector?

1Cassini image

A calibrated frame is selected from OPUS/PDS.

2Enhance contrast

The night side is stretched to expose faint bright features.

3Estimate background

Local brightness is measured so bright spots can be compared to nearby pixels.

4Find bright regions

Pixels above local thresholds become candidate bright regions.

5Form blobs

Neighboring bright pixels are grouped into multi-pixel blobs.

6Filter artifacts

Single-pixel hits, streaks, edges, and hot pixels are flagged.

7Score candidates

Brightness, SNR, size, shape, and temporal evidence set review priority.

8Human review

A reviewer labels the candidate before any scientific claim is made.

Roadmap

Next research milestones

  1. Static public review: make current detector outputs easy to inspect online.
  2. Shared labels: append reviewer decisions to a Google Sheet or equivalent shared table.
  3. Geometry: add Jupiter latitude/longitude for each candidate using SPICE/backplanes where possible.
  4. Temporal grouping: compare candidates across nearby frames within configurable lat/lon tolerance.
  5. Model comparison: train YOLO or another model only after enough reviewed examples exist.
